# tono-legal

Điều khoản sử dụng và Chính sách quyền riêng tư của app Tono, phục vụ qua
GitHub Pages. Đây là URL điền vào App Store Connect và cũng là URL app mở ra
từ màn hình mua.

- https://starnova-io.github.io/tono-legal/terms.html
- https://starnova-io.github.io/tono-legal/privacy.html

## Đừng sửa HTML ở đây

Ba file HTML trong repo này là BẢN XUẤT. Nguồn nằm trong repo `snapmoment` tại
`tono-service/app/legal.py`; sửa ở đó rồi chạy:

    python3 scripts/render_legal.py --out <repo này>

Sửa trực tiếp HTML sẽ tạo ra hai bản chữ khác nhau, và bản sai là bản mà cửa
hàng đọc.
